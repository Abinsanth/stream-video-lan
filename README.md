# stream-video-lan

Stream the videos on your computer to any device on the same Wi-Fi or hotspot. Pick a folder,
open the link in VLC: no copying, no re-encoding, no cloud. Seeking and several viewers at once
just work. Runs on macOS and Linux.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/Abinsanth/stream-video-lan/release/install.sh | sh
```

## Uninstall

```sh
lanstream --uninstall
```

Run `lanstream --help` for everything else.
